СТУДЕНЧЕСКИЙ АРХИВ — БЛОК 5

Для отправки студентам используйте:
Polytech_Block5_student_windows_x64.zip

Windows x64. Внутри — Python 3.12, JupyterLab, блокнот и оба корпуса.
Устанавливать Python или Conda и скачивать зависимости не требуется.

1. Скачайте ZIP на компьютер и распакуйте ВЕСЬ архив в локальную папку,
   например C:\Polytech. Не запускайте файлы прямо внутри ZIP.
2. Дважды щёлкните RUN_NOTEBOOK.cmd. На первом запуске дождитесь
   подготовки встроенного окружения и открытия JupyterLab в браузере.
3. Откройте Teaching_Block5.ipynb и выберите
   Kernel → Restart Kernel and Run All Cells.

Настройки по умолчанию:
CASE = "scooters"
MODE = "offline"
SENTIMENT_MODE = "frozen"
SHOW_INSTRUCTOR = False

Для Яндекса измените только CASE = "yandex", перезапустите ядро
и выполните все ячейки. Для обоих готовых корпусов интернет не нужен.

После первого запуска не переносите распакованную папку. Для нового
места распакуйте ZIP заново и перенесите свои ответы отдельно.
Не отправляйте студентам папку instructor из рабочего проекта.

SHA256SUMS.txt содержит контрольную сумму ZIP.
Результаты проверки пакета: VALIDATION.txt рядом с архивом.
